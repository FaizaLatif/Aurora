## Goal
Short, practical guides to modern Angular, each with a working example.

## User stories
1. As a visitor, I want a left menu listing topics, so I can navigate.
2. As a visitor, I want to click a topic and see its guide on the right.
3. As a visitor, I want topics ordered by the Angular version they appeared in.
4. As a visitor, I want a welcome page when no topic is selected, so I understand what Aurora is and how to use it.
5. As a visitor, I want a search filter at the top of the left menu,
   so I can quickly find a topic by title.
   - Filters the menu as I type
   - Case-insensitive
   - Shows "No topics found" when nothing matches
